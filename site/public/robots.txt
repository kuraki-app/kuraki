# used to describe — a page declaring an unregistered kuraki.app as canonical
# while served from pages.dev — can no longer happen by editing one page and
# forgetting another.
#
# WHEN kuraki.app IS REGISTERED AND BOUND TO THIS PAGES PROJECT:
#
#   1. Set SITE_URL=https://kuraki.app for the production build (or change the
#      default in astro.config.mjs).
#   2. Replace the two lines below with:
#
#          Allow: /
#          Sitemap: https://kuraki.app/sitemap-index.xml
#
# The sitemap is already generated on every build by @astrojs/sitemap; it is
# simply not advertised while crawling is closed.
